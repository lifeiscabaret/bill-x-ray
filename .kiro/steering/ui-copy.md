# UI copy rules

English is the default UI language. A Korean toggle is P1; when it exists, every English
label uses the Korean counterpart below.

## Record-state wording
- "Not in the final text" / 최종 조문에 없음
- "Effective date not set" / 시행일 미정
- "Left for further committee discussion" / 부대의견으로 계속 논의
- "Survives in another law" / 다른 법에 남음
- Unknown or unconfirmed: "Not verified" / 확인 불가

## Unverified states (work order §3)
Proposed labels: B finalizes them, and A checks them against the sources.

| State | English | Korean |
|---|---|---|
| Evidence missing | Evidence missing | 근거 누락 |
| Omission not verified | Omission not verified | 누락 여부 미확인 |
| Not found in that final version | Not found in this final version | 해당 최종본에서 발견되지 않음 |
| Same outcome confirmed in a separate law | Same outcome, separate law | 별도 법률에서 같은 결과 확인 |
| Link not confirmed | Not verified | 확인 불가 |

"Not found in this final version" never becomes "abolished" or "gone for good".

## Never
Evaluative words such as "broken promise", "lie", "failure", "trick" or "monster", or
"약속 파기", "거짓말", "실패", "꼼수". No scores for politicians, parties or bills.

## Evidence on screen
- Every path and status can show its evidence: source title, publisher, version, what the
  date means, the clause location, a short original-language excerpt and the original link.
- A translation, if shown, is labelled "Translation".
- Show date kinds separately: passed, promulgated, effective, applied.
- Politically divided cases present each position with its source and equal weight.

## Without colour or motion
- Every line type and status reads from its text label and line shape, not colour alone.
- Everything the scanner does by dragging also works with buttons and the keyboard.
- Respect reduced motion.

# UI copy rules

- Use record-state wording only: "최종 조문에 없음", "시행일 미정", "부대의견으로 계속 논의", "다른 법에 남음". In English: "Not in the final text", "Effective date not set", "Left for further committee discussion", "Survives in another law".
- Never use evaluative words such as "약속 파기", "거짓말", "실패", "꼼수", or English equivalents such as "broken promise", "lie", "failure", "trick".
- Every verdict shows its evidence: the official link in the original language, the clause location and the original excerpt. A translation, if shown, is labeled as a translation.
- Show date kinds separately: passed, promulgated, effective, applied.
- Politically divided cases present each position with its source and equal weight.
- Unknown is "확인 불가".
